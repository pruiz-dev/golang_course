# Урок 7: Функции

Функции — это главный строительный блок в Go. Мы уже писали код внутри функции `main()`, но теперь пришло время создавать свои собственные.

В Go функции очень гибкие. Их главная суперсила — возможность возвращать **сразу несколько значений**. Это настолько популярно, что 90% функций в реальном коде возвращают результат и ошибку: `result, err := doSomething()`.

### 1. Базовая функция
Тип аргумента пишется *после* его имени. Тип возвращаемого значения пишется *перед* открывающей скобкой `{`.
```go
func add(x int, y int) int {
    return x + y
}
```
*Секрет: если аргументы идут подряд и имеют одинаковый тип, его можно написать один раз в конце: `func add(x, y int) int`.*

### 2. Возврат нескольких значений
Чтобы вернуть несколько значений, их типы нужно взять в круглые скобки.
```go
func divide(a, b float64) (float64, string) {
    if b == 0 {
        return 0, "Деление на ноль!"
    }
    return a / b, "Успех"
}
```

### 3. Именованные возвращаемые значения
Ты можешь заранее дать имена возвращаемым переменным прямо в сигнатуре функции. Go сам создаст их (они будут равны zero value), и тебе достаточно будет просто написать `return` (так называемый "голый возврат" или naked return).
```go
func getStats() (min int, max int) {
    min = 10
    max = 100
    return // Go сам вернет текущие значения min и max
}
```
*Senior-совет: Использовать `return` без параметров удобно в коротких функциях. В длинных это ухудшает читаемость (непонятно, что именно возвращается в данный момент).*

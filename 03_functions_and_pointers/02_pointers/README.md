# Урок 8: Указатели (Pointers)

Указатели — это тема, на которой многие ломаются, но в Go они сделаны максимально просто (в отличие от C++, здесь нет арифметики указателей, поэтому выстрелить себе в ногу гораздо сложнее).

Каждая переменная в твоей программе хранится в оперативной памяти и имеет свой **адрес**.
Указатель — это просто переменная, которая хранит не само значение (например, `100`), а **адрес в памяти**, где лежит это значение (например, `0xc00001a0a8`).

### Два главных оператора: `&` и `*`

1. **Оператор `&` (Амперсанд) — "Дай мне адрес"**
Если у нас есть переменная `x`, то `&x` вернет её адрес в памяти.
```go
age := 25
fmt.Println(&age) // Выведет что-то вроде 0xc0000a0018
```

2. **Оператор `*` (Звездочка) — "Дай мне значение по этому адресу" (Разыменование)**
Если у нас есть адрес, мы можем посмотреть, что там лежит, или даже изменить это значение.
```go
age := 25
pointerToAge := &age // Тип этой переменной: *int (указатель на int)

// Читаем значение по адресу
fmt.Println(*pointerToAge) // Выведет 25

// Меняем значение прямо в памяти!
*pointerToAge = 30
fmt.Println(age) // Выведет 30 (мы изменили оригинальную переменную age!)
```

### Зачем это нужно? (Pass by Value)
В Go **все** аргументы в функции передаются **по значению** (копируются).
```go
func tryToChange(x int) {
    x = 99 // Это изменит только локальную КОПИЮ
}
```
Если ты передашь мегабайтную структуру в функцию, Go скопирует весь мегабайт. А если ты передашь её указатель, Go скопирует только крошечный 8-байтный адрес. Указатели позволяют функциям изменять оригинальные переменные и экономят память.

## Задание

Создай файл `main.go` в директории `03_functions_and_pointers/02_pointers`.

1. Создай переменную `score` (тип `int`) и присвой ей значение, например `100`.
2. Напиши функцию `doubleValue(val int)`, которая умножает переданное значение на 2.
3. Напиши вторую функцию `doublePointer(val *int)`, которая принимает *указатель* на число и умножает значение по этому адресу на 2. (Подсказка: `*val = *val * 2`).
4. Внутри `main`:
   - Выведи `score`.
   - Вызови `doubleValue(score)`.
   - Выведи `score` (оно не должно измениться).
   - Вызови `doublePointer(&score)` (передаем адрес!).
   - Снова выведи `score` (оно должно стать 200).

# Теория: Анатомия строки в Go — Байты против Рун

## 1. Что такое строка в Go под капотом?

В Go строка (`string`) — это **иммутабельная (только для чтения) последовательность байтов**.
В оперативной памяти переменная типа `string` занимает ровно **16 байт** (на 64-битной системе) и описывается структурой `StringHeader`:

```go
type StringHeader struct {
    Data uintptr // 8 байт: прямой указатель на массив байт в памяти
    Len  int     // 8 байт: количество БАЙТ в строке
}
```

Обрати внимание на два фундаментальных свойства:
1. **У строки нет поля `Cap` (вместимости)** в отличие от слайса. Строка жестко зафиксирована по длине.
2. **Байты строки неизменяемы**. Память, на которую указывает `Data`, защищена от прямой модификации (попытка написать `s[0] = 'A'` вызовет ошибку компиляции: *cannot assign to s[0]*).

## 2. Кодировка UTF-8: Почему 1 символ ≠ 1 байт

Исходный код в Go всегда пишется в кодировке **UTF-8**, и строковые литералы по умолчанию хранятся как UTF-8 последовательности байт.

UTF-8 — это кодировка **переменной длины**:
* Английские буквы и цифры (ASCII: `A-Z`, `a-z`, `0-9`) занимают **1 байт** (диапазон `0x00 - 0x7F`).
* Русские буквы (кириллица: `А-Я`, `а-я`) занимают **2 байта**.
* Редкие иероглифы, графические символы занимают **3 байта**.
* Эмодзи (`🔥`, `🚀`, `🎮`) занимают **4 байта**.

### Ловушка функции `len()`
Функция `len(s)` в Go считает **не количество символов, а количество физических БАЙТ**:

```go
s1 := "Go"
fmt.Println(len(s1)) // Выведет: 2 (2 ASCII символа по 1 байту)

s2 := "Привет"
fmt.Println(len(s2)) // Выведет: 12! (6 русских букв по 2 байта = 12 байт)

s3 := "🔥"
fmt.Println(len(s3)) // Выведет: 4! (1 эмодзи занимает 4 байта)
```

> ⚠️ **Главная ошибка новичков:** Пытаться валидировать длину логина или пароля пользователя («не менее 6 символов») через `len(password)`. Для русского слова "Кот" `len` равен 6, хотя там всего 3 буквы!

## 3. Ловушка индексации: `s[i]` возвращает `byte`, а не символ

Когда ты обращаешься к строке по индексу `s[i]`, Go возвращает **один байт** (тип `byte`, который является псевдонимом для `uint8`):

```go
s := "Привет"
fmt.Printf("%T: %v\n", s[0], s[0]) // uint8: 208 (0xD0)
```

Русская буква `П` состоит из двух байт: `0xD0` и `0x9F`.  
Взяв `s[0]`, ты оторвал от буквы первую половинку.  
Если ты попытаешься распечатать её как символ:
```go
fmt.Println(string(s[0])) // Выведет:  (символ ошибки декодирования / Replacement Character)
```

## 4. Что такое `rune` (Руна)?

Чтобы работать с символами Unicode независимо от того, сколько байт они занимают, в Go есть тип **`rune`**.

* **`rune`** — это встроенный псевдоним (type alias) для типа **`int32`** (4 байта).
* Руна представляет собой **одну кодовую точку Unicode (Unicode Code Point)**.
* Поскольку 4 байта (32 бита) с запасом покрывают абсолютно все существующие в мире символы Unicode (все алфавиты мира, иероглифы, исторические знаки и эмодзи), любая руна гарантированно хранит ровно один неделимый символ.

Литералы рун в коде всегда выделяются **одинарными кавычками**:
```go
var r1 rune = 'A'  // int32 со значением 65 (код ASCII)
var r2 rune = 'П'  // int32 со значением 1055 (Unicode код буквы П)
var r3 rune = '🔥' // int32 со значением 128293
```

## 5. Как правильно считать количество символов?

Для подсчета реального числа символов (кодовых точек) используется функция **`utf8.RuneCountInString()`** из стандартного пакета `"unicode/utf8"`:

```go
import "unicode/utf8"

text := "Привет, Go! 🔥"
fmt.Println("Байт:", len(text))                      // 19 байт
fmt.Println("Символов:", utf8.RuneCountInString(text)) // 13 рун
```

## 6. Два способа итерации по строке

### Способ 1: Итерация по байтам через обычный `for`
```go
str := "Go"
for i := 0; i < len(str); i++ {
    fmt.Printf("Индекс: %d, Байт: %x\n", i, str[i])
}
```
*Шаг всегда строго +1 байт. Для многобайтовых символов UTF-8 разрывает буквы.*

### Способ 2: Итерация по рунам через `for range` (Магия компилятора Go)
Создатели Go встроили в цикл `range` специальный декодер UTF-8 на лету:

```go
text := "Прув"
for idx, r := range text {
    fmt.Printf("Байтовое смещение: %d, Руна: %c (код: %U)\n", idx, r, r)
}
```
Вывод:
```
Байтовое смещение: 0, Руна: П (код: U+041F)
Байтовое смещение: 2, Руна: р (код: U+0440)
Байтовое смещение: 4, Руна: у (код: U+0443)
Байтовое смещение: 6, Руна: в (код: U+0432)
```

> 💡 **Обрати внимание на индексы (`idx`):** `0`, `2`, `4`, `6`!  
> В цикле `range` переменная `idx` — это **НЕ порядковый номер символа** (0, 1, 2, 3), а **смещение первого байта этой руны в физическом массиве байт**. Так как каждая русская буква занимает 2 байта, счетчик смещения перескакивает сразу через 2!

### Способ 3: Превращение в срез рун `[]rune(s)`
Если тебе нужен доступ к $N$-му символу по строгому порядковому номеру:
```go
runes := []rune("Привет") // Выделяется новый срез []int32
fmt.Println(string(runes[0])) // "П"
fmt.Println(len(runes))       // 6
```
*(Помни: это превращение аллоцирует новый срез в памяти! Для простого обхода лучше использовать `range`).*

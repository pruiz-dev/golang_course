# План модуля: 03_pointers_and_memory

## Цель модуля
Понять, как Go работает с оперативной памятью. Научиться передавать данные по ссылке, избегать паник с нулевыми указателями (`nil pointer dereference`) и разобраться в том, как компилятор решает, где хранить данные (Стек или Куча).

## Фаза 1 (Muscle Memory)
- **Practice 01: Базовые указатели и передача параметров.** Написание функций, которые мутируют (изменяют) переданные переменные через указатели, и сравнение их с передачей по значению (копированием).
- **Practice 02: Ловушки nil-указателей.** Безопасная инициализация указателей, проверка на `nil`, вызов паники (panic) и её предотвращение.

## Фаза 2 (Deep Dive)
- **Practice 03: Escape Analysis (Стек vs Куча).** Использование флага компилятора `-m` для отслеживания того, как переменные "убегают" в кучу (Heap), и как это влияет на производительность (Garbage Collector).
- **Practice 04: Изменение адреса vs Изменение значения.** Понимание разницы между `*p = 5` (изменение значения в памяти) и `p = &b` (изменение самого адреса указателя локально).

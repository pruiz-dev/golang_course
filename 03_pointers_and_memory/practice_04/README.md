# Практика: Иллюзия телепортации (Swap)

## Задача (Бизнес-требование)
Твоя задача — написать утилиту для смены местами (swap) значений двух переменных. 
Стажер попытался написать функцию обмена, просто поменяв указатели местами, но у него ничего не вышло — переменные в `main` остались на своих местах. 
Тебе нужно написать две функции: одну с ошибкой стажера (чтобы показать, как делать нельзя), а вторую — правильную.

## Критерии приемки (Acceptance Criteria)
1. Создай исполняемую программу.
2. Напиши функцию `FailedSwap(a *int, b *int)`. Внутри нее попытайся поменять `a` и `b` местами **без использования звездочек**. 
3. Напиши функцию `SuccessfulSwap(a *int, b *int)`. Внутри нее поменяй реальные значения местами **с использованием разыменования** (`*`).
4. В функции `main`:
   - Создай переменные `x = 10` и `y = 20`.
   - Вызови `FailedSwap(&x, &y)` и выведи значения `x` и `y`. Убедись, что они **НЕ** поменялись (остались 10 и 20).
   - Вызови `SuccessfulSwap(&x, &y)` и выведи значения. Убедись, что они поменялись (стали 20 и 10).

## Архитектурные подсказки
- В Go есть потрясающая фишка: множественное присваивание. Чтобы поменять две переменные местами, не нужна третья временная переменная (как в C++ или Java). Можно написать прямо так: `a, b = b, a`.
- В `FailedSwap` используй множественное присваивание для самих указателей.
- В `SuccessfulSwap` используй множественное присваивание для разыменованных указателей (со звездочками).

# Теория: Значение по адресу vs Сам адрес

Часто возникает путаница между двумя операциями: изменением данных **по указателю** и изменением **самого указателя**. Давай разберем это раз и навсегда.

Представь, что указатель — это листок бумаги, на котором записан адрес дома (например, "ул. Пушкина, 5"). А значение — это люди, которые живут в этом доме.

## Сценарий 1: Изменение значения (`*p = ...`)
Когда ты используешь разыменование (звездочку `*`), ты говоришь программе: *"Возьми адрес с листка, дойди до дома и поменяй там жильцов"*.

```go
func changeValue(p *int) {
    *p = 500 // Мы пошли по адресу и положили в память число 500
}
```
Это повлияет на оригинальную переменную, потому что мы ходили в оригинальный "дом".

## Сценарий 2: Изменение самого адреса (`p = ...`)
Вспомни базовое правило Go: **Всё передается по значению (копируется)**.
Когда ты передаешь указатель в функцию, Go делает **копию самого листка бумаги**. Теперь у тебя два листка с надписью "ул. Пушкина, 5".

Что будет, если внутри функции ты напишешь так?
```go
func changePointer(p *int) {
    newHouse := 999
    p = &newHouse // Мы зачеркнули адрес на НАШЕМ листке и написали новый адрес
}
```
Здесь нет звездочки `*`. Это значит, что мы не пошли в дом. Мы просто взяли свою копию листка бумаги и переписали на ней адрес.
Оригинальный листок бумаги, который остался в функции `main`, **никак не изменился**. Он всё еще указывает на старый дом.

> **Вывод:** Присвоение новому указателю (без `*`) внутри функции имеет нулевой эффект на внешний мир. Переменная `p` внутри функции — это просто локальная переменная, хранящая адрес. Если ты ее перезапишешь, ты просто потеряешь связь с оригиналом.

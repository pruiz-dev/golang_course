# Теория: Указатели и Память

В Go **Всё передается по значению (копируется)**.
Когда ты передаешь переменную в функцию, Go создает её полную копию. Функция работает с клоном. Оригинальная переменная остается нетронутой. 
Если переменная весит несколько мегабайт, такое копирование убьет производительность. А если нам нужно, чтобы функция действительно изменила оригинал (например, обновила баланс пользователя) — копирование делает это невозможным.

Для решения этих проблем существуют указатели.

## Что такое Указатель (Pointer)?
Указатель — это просто переменная, которая хранит не само значение (например, `42`), а **адрес в оперативной памяти**, где лежит это значение (например, `0xc00001a0a8`).

### Два главных оператора: `&` и `*`

1. **Оператор взятия адреса (`&`)**
   Если у тебя есть переменная, и ты хочешь узнать, где она лежит в памяти, поставь перед ней `&`.
   ```go
   age := 25
   fmt.Println(&age) // Выведет что-то вроде 0xc00001a0a8
   ```

2. **Оператор разыменования (`*`)**
   Работает в двух контекстах:
   
   **А) При указании типа переменной (Type Declaration):** 
   Означает "это указатель на такой-то тип".
   ```go
   var p *int // p - это переменная, которая может хранить адрес памяти, где лежит int.
   p = &age   // сохранили адрес age в переменную p
   ```

   **Б) При работе со значением (Dereferencing):**
   Если `p` хранит адрес, то `*p` означает "пойди по этому адресу и дай мне то, что там лежит".
   ```go
   fmt.Println(*p) // Выведет 25
   *p = 30         // Мы пошли по адресу памяти и перезаписали там значение на 30!
   fmt.Println(age) // Выведет 30 (мы изменили оригинал!)
   ```

## Разница между Value и Pointer
```go
// Функция получает КОПИЮ. Изменения внутри не повлияют на оригинал.
func updateValue(v int) {
    v = 99
}

// Функция получает АДРЕС. Изменения по этому адресу повлияют на оригинал.
func updatePointer(p *int) {
    *p = 99
}
```

> **Золотое правило:** Используй указатели, когда тебе нужно **изменить** (мутировать) данные, переданные в функцию, или когда данные **очень большого размера** (чтобы не копировать их при передаче). В остальных случаях всегда передавай по значению — это быстрее и безопаснее!

# Практика: Система обновления метрик игрока

*Добро пожаловать в режим "Guided Problem Solving". Здесь нет пошаговых инструкций, только бизнес-требования и архитектурные рамки.*

## Задача (Бизнес-требование)
Представь, что ты разрабатываешь ядро для RPG-игры. В игре у персонажа есть два важных показателя: 
- Очки здоровья (HP), целочисленное значение.
- Статус "В бою" (inCombat), логическое (boolean) значение.

Тебе нужно написать логику, которая будет изменять эти показатели. Однако стажер уже пытался написать функцию для изменения HP, и она не сработала (показатель не изменился). Твоя задача — продемонстрировать разницу между неправильным подходом (передача по значению) и правильным (передача по указателю).

## Критерии приемки (Acceptance Criteria)
1. Проект должен содержать один исполняемый `main.go`. (Пакет `main`). Можешь всё написать в одном файле.
2. Исходные данные персонажа (внутри `main`): HP = 100, InCombat = false.
3. Должна быть функция `TryHeal(hp int)`, которая пытается прибавить 50 очков здоровья к переданному числу. (Это имитация кода стажера, которая не изменит оригинал).
4. Должна быть функция `TakeDamage(...)`, которая принимает **указатель** на здоровье и отнимает 30 очков. Она обязана изменить оригинальную переменную.
5. Должна быть функция `ToggleCombat(...)`, которая принимает **указатель** на статус "В бою" и инвертирует его (меняет `false` на `true` или наоборот).
6. В функции `main` ты должен:
   - Вызвать `TryHeal`. Вывести значение здоровья (оно должно остаться 100).
   - Вызвать `TakeDamage`. Вывести значение здоровья (оно должно стать 70).
   - Вызвать `ToggleCombat`. Вывести статус (должен стать true).
   - *(Дополнительно)* Вывести на экран физические адреса памяти (через `fmt.Printf("%p\n", ...)`) переменных здоровья в функции `main` и внутри функции `TakeDamage`, чтобы доказать, что это один и тот же адрес.

## Архитектурные подсказки
- Для вывода адреса памяти в консоль используй форматирование `%p` в функции `fmt.Printf`. Чтобы передать туда переменную, перед ней нужно поставить `&` (взять адрес), либо передать сам указатель.
- В функции `ToggleCombat` при разыменовании указателя на `bool` и инвертировании значения, будь аккуратен с синтаксисом: `*ptr = !*ptr`.

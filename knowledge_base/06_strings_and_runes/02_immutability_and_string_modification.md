# База Знаний: Иммутабельность строк и Способы их модификации

## 1. Архитектурная причина иммутабельности строк

В Go строки (`string`) фундаментально **неизменяемы (Read-Only)**.
Попытка изменить байт по индексу пресекается компилятором:

```go
s := "hello"
s[0] = 'H' // Ошибка компиляции: cannot assign to s[0]
```

### Зачем Go запрещает менять строки на месте?
1. **Потокобезопасность (Thread Safety) без блокировок:**  
   Строку могут одновременно читать сотни горутин. Состояние гонки (*Data Race*) исключено на уровне языка, потому что никто не может переписать данные в фоновом режиме. Мьютексы для чтения строк не требуются.
2. **Аппаратная защита памяти (Секция `.rodata`):**  
   Строковые литералы (`"hello"`, `"Пароль"`) компилятор размещает в специальном сегменте бинарного файла — **`.rodata`** (*read-only data*). Эта область памяти на уровне операционной системы защищена от записи. Если бы рантайм попытался изменить байт в `.rodata`, процессор сгенерировал бы аппаратное прерывание (*Segmentation Fault / SIGSEGV*).
3. **Бесплатная нарезка и передача:**  
   Взятие подстроки `s[2:5]` или передача строки в функцию копирует лишь 16-байтовую структуру `StringHeader` (`Data`, `Len`). Исходные данные остаются на месте, не аллоцируя новую память.

## 2. Механика редактирования: Два подхода

Поскольку изменить существующую строку невозможно, любая модификация сводится к одной формуле:
`Исходная строка -> Изменяемый срез (мутация) -> Новая строка в памяти`

В Go есть два принципиально разных типа срезов для этой операции:

---

### Подход А: Срез байтов `[]byte(s)` (Только для ASCII)

```go
s := "4111-2222-3333-4444"
b := []byte(s) // 1. Выделяется срез []uint8 (копия данных)
b[5] = '*'     // 2. Быстрая замена 1 байта на месте
res := string(b) // 3. Аллокация новой строки
```

* **Плюсы:** Минимальный расход памяти (1 байт на ячейку), максимальная скорость.
* **Сфера применения:** Номера карт, IP-адреса, английский текст, JSON-ключи, системные протоколы.

#### Ловушка UTF-8: Разрыв многобайтовых символов
Если строка содержит кириллицу или эмодзи, попытка редактировать её через `[]byte` приводит к повреждению кодировки:

```go
ru := "Пароль" // Русская 'П' = 2 байта: [0xD0 0x9F]
b := []byte(ru)
b[0] = '*' // Заменили только 1-й байт буквы 'П'
fmt.Println(string(b)) // Выведет: *ароль
```
> **Что за символ ``?** Это официальный **Unicode Replacement Character** (`U+FFFD`). Терминалы и браузеры выводят его, когда видят разорванный или невалидный байт UTF-8 (в данном случае оторванный хвост `0x9F`).

---

### Подход Б: Срез рун `[]rune(s)` (Универсально для всего Unicode)

Для работы с кириллицей, иероглифами и эмодзи строку преобразуют в срез рун (`[]int32`):

```go
ru := "Пароль"
runes := []rune(ru) // 1. Распаковывает строку в срез int32
runes[0] = '*'      // 2. Заменяет целую 2-байтовую руну 'П' на 1-байтовую руну '*'
res := string(runes) // 3. Упаковывает срез обратно в валидный UTF-8
fmt.Println(res)    // "*ароль" (Идеально, никаких кракозябр!)
```

#### Что делает `string(runes)` под капотом?
Рантайм Go заново проходит по срезу `int32` и кодирует каждый символ в UTF-8.
* Руна `'*'` будет закодирована в **1 байт**.
* Руна `'а'` будет закодирована в **2 байта**.
* Итоговая байтовая длина строки автоматически пересчитывается.

## 3. Таблица затрат памяти и аллокаций

| Операция | Тип в памяти | Аллокации в куче | Расход RAM |
| :--- | :--- | :--- | :--- |
| `b := []byte(s)` | `[]uint8` | 1 аллокация | N байт (N — длина в байтах) |
| `newS := string(b)` | `string` | 1 аллокация | N байт |
| `r := []rune(s)` | `[]int32` | 1 аллокация | **4 * K байт** (K — количество символов) |
| `newS := string(r)` | `string` | 1 аллокация | Новая_длина байт |

## 4. Идиоматичные паттерны практики 02

### Паттерн 1: Безопасное маскирование диапазона символов (`MaskRunes`)
Принимает полуинтервал [start, end) и проверяет валидность границ, возвращая `error`:

```go
func MaskRunes(s string, start, end int, mask rune) (string, error) {
	runes := []rune(s)

	if start > end || start < 0 || end > len(runes) {
		return "", fmt.Errorf(
			"ERROR: Incorrect parameters: start=%d, end=%d, len=%d",
			start, end, len(runes),
		)
	}

	for i := start; i < end; i++ {
		runes[i] = mask
	}

	return string(runes), nil
}
```

### Паттерн 2: Универсальное маскирование номеров карт (`MaskCardNumber`)
Не использует жестко зашитые позиции индексов («магические числа»), а считает **реальные цифры**:
* Пропускает разделители (`-`, пробелы).
* Работает с любым форматом номера (с дефисами, с пробелами или слитно).
* Использует цикл Go 1.22: `for i := range len(b)`.

```go
func MaskCardNumber(card string) string {
	b := []byte(card)
	digitsCount := 0
	for i := range len(b) {
		c := b[i]
		if c >= '0' && c <= '9' {
			digitsCount++
			if digitsCount >= 5 && digitsCount <= 12 {
				b[i] = '*'
			}
		}
	}
	return string(b)
}
```

## 5. Полный эталонный код практики 02 (`main.go`)

```go
package main

import (
	"fmt"
)

func main() {
	str1 := "Пароль"

	// 1. Демонстрация разрушения кодировки при наивной побайтовой модификации
	s1 := MaskBytesNaive(str1)
	fmt.Printf("s1 is: %v\n\n", s1) // Выведет: *ароль

	// 2. Безопасное маскирование рун с проверкой ошибки
	s2, err := MaskRunes(str1, -22, 5, '%')
	if err != nil {
		fmt.Printf("Error: %v\n\n", err)
	} else {
		fmt.Printf("s2 is: %v\n\n", s2)
	}

	// 3. Маскирование банковской карты с сохранением дефисов
	cardNumber := "4111-2222-3333-4444"
	s3 := MaskCardNumber(cardNumber)
	fmt.Printf("s3 is: %v\n\n", s3) // Выведет: 4111-****-****-4444
}

// MaskBytesNaive наглядно иллюстрирует ошибку разрыва UTF-8 символа.
func MaskBytesNaive(s string) string {
	bytesArr := []byte(s)
	bytesArr[0] = '*'
	return string(bytesArr)
}

// MaskRunes заменяет диапазон рун с валидацией границ.
func MaskRunes(s string, start, end int, mask rune) (string, error) {
	runes := []rune(s)

	if start > end || start < 0 || end > len(runes) {
		return "", fmt.Errorf(
			"ERROR: Incorrect parameters:\n"+
				"start: %d\n"+
				"end: %d\n"+
				"len(runes): %d\n\n",
			start, end, len(runes),
		)
	}

	for i := start; i < end; i++ {
		runes[i] = mask
	}

	return string(runes), nil
}

// MaskCardNumber маскирует цифры с 5 по 12, сохраняя дефисы и пробелы.
func MaskCardNumber(card string) string {
	b := []byte(card)
	digitsCount := 0
	for i := range len(b) {
		c := b[i]
		if c >= '0' && c <= '9' {
			digitsCount++
			if digitsCount >= 5 && digitsCount <= 12 {
				b[i] = '*'
			}
		}
	}
	return string(b)
}
```

## 6. Сводная шпаргалка к собеседованиям

1. **Можно ли изменить символ строки напрямую `s[0] = 'a'`?**  
   Нет, строки в Go строго иммутабельны. Компилятор выдаст ошибку.
2. **Где хранятся строковые литералы?**  
   В секции `.rodata` исполняемого файла, защищенной операционной системой от записи.
3. **Когда использовать `[]byte(s)`, а когда `[]rune(s)`?**  
   * `[]byte(s)` — только когда строка гарантированно ASCII (латиница, цифры). Это экономит память (1 байт/символ).  
   * `[]rune(s)` — всегда, когда в строке может быть кириллица, эмодзи или любые многобайтовые символы UTF-8.
4. **Что происходит при конвертации `string(runes)`?**  
   Go выделяет новую строку в куче и повторно кодирует каждую 4-байтовую руну в UTF-8 переменной длины (1–4 байта).

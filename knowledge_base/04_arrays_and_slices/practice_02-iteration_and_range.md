# База Знаний: Обход Массивов и Слайсов (`range`)

В Go цикл `for ... range` — это основной инструмент для обхода коллекций (массивов, слайсов, хэш-таблиц). При обходе массивов и слайсов он возвращает два значения: `index` (индекс элемента) и `value` (копия значения).

Понимание того, что происходит "под капотом" на каждой итерации, критически важно для написания быстрого и безопасного кода.

## 1. Обход с получением значения (`for i, v := range`)

```go
for index, value := range collection {
    // ...
}
```

**Что происходит под капотом:**
1. Создается копия "заголовка" слайса (или всего массива, если мы итерируемся по массиву по значению).
2. Начинается упорядоченный обход элементов в памяти.
3. На каждой итерации Go **аппаратно копирует** очередное значение из оригинального массива/слайса и кладет эту копию в локальную переменную `value` (или `v`).
4. **Важно:** Переменная `v` — это изолированная песочница. 

### Ошибка новичков (Мутация копии)
Если ты попытаешься изменить `v`, оригинальный массив **НЕ изменится**.
```go
for _, v := range loot {
    v = "Мусор" // Изменится только локальная переменная v, в массиве останется старый лут!
}
```

### Проблема производительности (Огромные структуры)
Если массив содержит тяжелые структуры (например, по 1 Мегабайту каждая), цикл `for _, v := range` заставит процессор **копировать 1 Мегабайт памяти на каждой итерации** из базового массива в переменную `v`. Это катастрофически замедлит программу (повышенная нагрузка на CPU и шину памяти).

## 2. Обход только по индексу (`for i := range`)

```go
for index := range collection {
    // Обращение идет напрямую: collection[index]
}
```

**Что происходит под капотом:**
1. Создается копия заголовка.
2. Цикл выдает только индекс текущего элемента (`i`), не копируя сами данные в отдельную переменную.
3. Ты обращаешься к элементу напрямую через операцию смещения в памяти: `collection[i]`.

### Когда использовать этот способ?
1. **Мутация оригинала:** Если тебе нужно изменить данные прямо внутри оригинального массива/слайса.
   ```go
   for i := range loot {
       loot[i] = "Мусор" // Это физически перезапишет память внутри массива!
   }
   ```
2. **Экстремальная оптимизация:** Если ты работаешь с массивом гигантских структур. Обращение по индексу `collection[i].Field` не копирует всю гигантскую структуру, процессор просто прыгает по нужному адресу в памяти и читает одно конкретное поле за время `O(1)`.

## 3. Best Practices (Что выбрать?)
* **Нужно только чтение и данные легкие (числа, строки, указатели)?**
  Используй `for _, v := range`. Код выглядит чисто, читается как обычный английский текст.
* **Нужно менять оригинальные элементы?**
  Используй `for i := range`.
* **Массив содержит "тяжелые" объекты?**
  Используй `for i := range`, чтобы не убить CPU копированием.

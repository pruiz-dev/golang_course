# База Знаний: Указатели на массивы и Синтаксический сахар

## 1. Зачем передавать массив по указателю?
Как мы выяснили ранее, массивы в Go передаются в функции **по значению** (создается полная копия всех данных в памяти). Если массив весит несколько мегабайт (например, `[1000000]int`), передача его в функцию заблокирует процессор на копирование огромного блока памяти, а любые изменения затронут только эту локальную копию.

Чтобы избежать копирования и получить возможность изменять оригинальный массив, используется **указатель на массив**:
```go
// Тип: указатель на массив из 5 интов
func EncryptKey(arrPtr *[5]int) {
    // ...
}
```

## 2. Хардкорное разыменование (Теоретически правильное)
С точки зрения строгой теории указателей, чтобы изменить элемент по указателю, нужно сначала "добраться" до самого массива (разыменовать указатель с помощью `*`), а уже потом применять индекс `[i]`.

Поскольку оператор индекса `[]` имеет более высокий приоритет, чем звездочка `*`, мы обязаны использовать скобки:
```go
func EncryptKey(arrPtr *[5]int) {
    for i := range *arrPtr {
        (*arrPtr)[i] *= 2 // Сначала получаем массив, потом берем i-тый элемент
    }
}
```
Этот код теоретически безупречен, но визуально перегружен.

## 3. Синтаксический сахар Go (Middle-уровень)
Создатели языка Go понимали, что писать `(*arrPtr)[i]` каждый раз — это неудобно и портит читаемость. Поэтому в компилятор встроен механизм автоматического разыменования (syntactic sugar) для указателей на массивы (а также для структур).

Если переменная является указателем на массив, ты можешь обращаться к её индексам и итерироваться по ней так, **как будто это обычный массив**. Компилятор сам подставит нужные звездочки под капотом.

Идиоматичный код выглядит так:
```go
func EncryptKey(arrPtr *[5]int) {
    // Компилятор сам разыменует arrPtr для range
    for i := range arrPtr { 
        // Компилятор сам разыменует arrPtr перед применением [i]
        arrPtr[i] *= 2
    }
}
```
Этот подход является стандартом в Go-разработке. Он сохраняет чистоту кода, оставляя всю мощь работы с указателями и мутацией оригинальной памяти.

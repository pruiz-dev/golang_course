# База Знаний: Итерация по Мапе и Рандомизация

Обход (итерация) элементов мапы осуществляется с помощью цикла `for range`. 

```go
colors := map[string]string{
    "Red":   "Красный",
    "Green": "Зеленый",
    "Blue":  "Синий",
}

for key, value := range colors {
    fmt.Printf("%s -> %s\n", key, value)
}
```

## Главная архитектурная особенность: Хаос
В языке Go **порядок итерации по мапе намеренно рандомизирован**. 
При каждом новом запуске цикла `for range` компилятор под капотом генерирует случайное число (random seed) и начинает обход внутренней структуры памяти (бакетов) со случайного места. 

Из-за этого порядок вывода элементов при каждом запуске программы будет разным.

### Философия: Зачем создатели Go это сделали?
В других языках программирования ранних версий порядок вывода элементов из хэш-таблиц был стабильным в рамках одной версии языка (он зависел от внутреннего алгоритма хэширования). 
Программисты замечали эту стабильность и начинали писать код (бизнес-логику), который **опирался на этот порядок** (например, брали "первый" выведенный элемент, ожидая, что это всегда будет один и тот же ключ).

Когда авторы языка обновляли алгоритм хэширования в новой версии для улучшения производительности, порядок элементов менялся, и логика программ ломалась в продакшене у тысяч компаний по всему миру.

Чтобы защитить программистов от этой фатальной ошибки, создатели Go пошли на радикальный шаг: они добавили рандомизатор, чтобы программист **физически не мог** написать код, зависящий от порядка обхода мапы. Баг вылезет сразу при первой же отладке.

## Как получить отсортированные данные из мапы?
Поскольку мапа — это принципиально неупорядоченная структура (мешок с данными), для вывода ключей в строгом порядке (например, по алфавиту) нужно использовать дополнительный слайс.

**Паттерн сортировки:**
1. Создать слайс ключей.
2. Пройтись по мапе и скопировать все ключи в слайс.
3. Отсортировать слайс (`sort.Strings`).
4. Пройтись по отсортированному слайсу и достать значения из мапы.

```go
import "sort"

// ...

// 1. Создаем слайс нужной длины
keys := make([]string, 0, len(colors))

// 2. Собираем ключи
for k := range colors {
    keys = append(keys, k)
}

// 3. Сортируем слайс
sort.Strings(keys)

// 4. Выводим значения в строгом алфавитном порядке ключей
for _, k := range keys {
    fmt.Printf("%s -> %s\n", k, colors[k])
}
```

**Золотое правило:** На код-ревью строго запрещено пропускать код, который ожидает предсказуемого порядка при прямой итерации по мапе!

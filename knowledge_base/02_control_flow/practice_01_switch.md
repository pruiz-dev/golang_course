# База Знаний: Управляющая конструкция `switch`

Этот документ — исчерпывающая шпаргалка для подготовки к собеседованию и повседневной работы с оператором `switch` в Go. В отличие от C/C++ или Java, в Go `switch` переработан для максимальной безопасности и чистоты кода.

## 1. Инициализация (Init statement) и Область видимости
Как и в `if`, в `switch` можно создать переменную прямо перед проверкой условия, ограничив её область видимости (scope) только рамками самого блока `switch`.
Синтаксис разделяется точкой с запятой `;`:
```go
switch status := getStatus(); status {
case 200, 201:
    fmt.Println("Успех")
}
// Переменная status здесь больше не существует!
```
**Анатомия конструкции:**
1. `status := getStatus()` — это **блок инициализации**. Выполняется один раз. Мы создаем локальную переменную.
2. `;` — разделитель.
3. `status` (второе слово) — это **значение, которое мы будем сравнивать**.

**Зачем это нужно на собеседовании?**
Ограничение области видимости защищает внешнюю среду от "мусорных" временных переменных и предотвращает баги, связанные со случайным затенением (shadowing).

## 2. Безопасность по умолчанию (отсутствие автоматического `fallthrough`)
В классических языках забытый `break` приводит к проваливанию в следующий `case`. Go спасает от этой ошибки:
* В Go `break` встроен в `case` **по умолчанию**. Как только логика внутри `case` выполнена, `switch` завершается. 
* Если проваливание в следующий `case` всё же нужно, используется явное ключевое слово **`fallthrough`**.

```go
switch status := getStatus(); status {
case "error":
    fmt.Println("Произошла ошибка")
    fallthrough // Принудительно выполнит код следующего case (unknown)!
case "unknown":
    fmt.Println("Статус неизвестен")
}
```

## 3. Множественные значения в одном `case`
Если несколько значений требуют одинаковой обработки, идиоматичный способ в Go — перечислить их через запятую. Это элегантная замена громоздким проверкам через логическое ИЛИ (`||`).
```go
case 400, 401, 403, 404:
    fmt.Println("Ошибка на стороне клиента")
```

## 4. Пустой `switch` (Switch true) и отсутствие интервалов
В Go **нет** специального синтаксиса для интервалов вроде `case 1..5:`.
Чтобы проверять диапазоны значений, используется **пустой switch** (`switch { ... }` без передаваемой переменной). В этом случае он работает как `switch true`, и в каждом `case` пишется полноценное логическое выражение:

```go
score := 85
switch { // Условие не передано (считай, что тут скрыто true)
case score >= 90 && score <= 100:
    fmt.Println("Отлично")
case score >= 80 && score < 90:
    fmt.Println("Хорошо")
default:
    fmt.Println("Надо подтянуть")
}
```
Такой подход полностью заменяет длинные каскады `if-else if-else` и является стандартом (Best Practice) в Go. 

## 5. Блок `default`
Блок `default` является аналогом `else`. Он выполняется только в том случае, если ни один из вариантов `case` не подошел. Обязателен к использованию для обработки непредвиденных значений.

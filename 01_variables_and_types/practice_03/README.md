# Практика 03: Переполнение и Усечение

## Задание

Давай на практике посмотрим, как ломаются данные при неправильной работе с типами. Это финальная практика модуля `01_variables_and_types`.

### Шаги:
1. Создай папку `practice_03`, инициализируй в ней модуль `go mod init practice_03`.
2. Создай файл `main.go`. Напиши код, который делает следующее:

**Часть 1: Переполнение (Overflow)**
- Создай переменную типа `uint8` со значением `255`.
- Прибавь к ней `1`. Выведи результат.
- Создай переменную типа `int8` со значением `127`.
- Прибавь к ней `1`. Выведи результат. Посмотри, в какое отрицательное число оно "перепрыгнет".

**Часть 2: Усечение при конвертации**
- Создай переменную типа `int16` со значением `1000`.
- Создай переменную типа `int8` и присвой ей значение из первой переменной (потребуется явное приведение `int8(...)`).
- Выведи результат `int8`. 

**Часть 3: Конвертация float в int**
- Создай переменную `float32` со значением `2.99`.
- Сконвертируй её в `int` и выведи. Убедись, что округления по правилам математики не происходит.

**Часть 4: Компилятор не даст в обиду (только константы)**
- Попробуй написать `var impossible int8 = 1000`. 
- Убедись, что IDE и компилятор (`go run .`) ругаются и не дают даже запустить код. Закомментируй эту строку после проверки, чтобы программа скомпилировалась.

Жду твой готовый `main.go` и наблюдения о том, какое число получилось при усечении `1000` до `int8`!

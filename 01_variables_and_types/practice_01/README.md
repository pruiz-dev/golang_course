# Практика 01: Механика аллокации и размеры типов

Привет. Пора забыть про то, что переменная — это просто коробочка для данных. В Go, как в системном языке, каждая переменная имеет четкий размер в памяти и тип, который компилятор строго контролирует.

## Теория под капотом

1. **Строгая типизация и отсутствие неявных преобразований:**
   В отличие от C или JavaScript, Go никогда не приведет `int32` к `int64` за тебя. Это сделано для предотвращения скрытых багов, когда данные могут быть случайно обрезаны. Если тебе нужно сложить `int32` и `int64`, ты обязан явно конвертировать один тип в другой.

2. **Архитектурно-зависимые типы:**
   Типы `int` и `uint` имеют размер 32 бита на 32-битных системах и 64 бита на 64-битных системах. Аналогично `uintptr`. Если твой код завязан на размер типа (например, сетевые протоколы или бинарные форматы), используй типы с фиксированным размером: `int32`, `uint64` и т.д.

3. **`unsafe.Sizeof`:**
   В пакете `unsafe` есть функция `Sizeof`, которая возвращает размер переменной в байтах. Она не учитывает память, на которую переменная может ссылаться (например, для строк она вернет размер структуры `StringHeader` (16 байт на x64), а не длину самих символов).

4. **Zero value (нулевое значение):**
   При объявлении переменной без явной инициализации (`var x int`) Go гарантированно зануляет память. Никакого "мусора" из оперативной памяти не будет. `int` станет `0`, `string` — `""`, `bool` — `false`, указатели — `nil`.

## Боевое задание

Твоя задача — написать программу, которая анализирует размеры различных типов данных в памяти на твоей машине.

### Требования к реализации:

1. Инициализируй Go-модуль. Открой терминал в папке `practice_01` и выполни `go mod init practice_01`.
2. Создай два файла:
   - `main.go` — точка входа, где будет происходить вызов логики и вывод результатов.
   - `analyzer.go` — файл с логикой.
3. В файле `analyzer.go` напиши несколько отдельных функций со строгой типизацией аргумента (например, `PrintIntInfo(v int)`, `PrintInt32Info(v int32)`, `PrintInt64Info(v int64)`, `PrintStringInfo(v string)`, `PrintBoolInfo(v bool)`). Каждая функция должна выводить в консоль:
   - Тип переданной переменной (используй пакет `fmt` и спецификатор `%T`).
   - Размер переменной в байтах (используй `unsafe.Sizeof`).
4. В `main.go` вызови соответствующие функции для следующих переменных:
   - Переменная типа `int` (оставь zero value)
   - Переменная типа `int32` (любое значение)
   - Переменная типа `int64` (любое значение)
   - Строка `"Hello, Go! Это очень длинная строка для теста."`
   - Пустая строка `""`
   - Переменная типа `bool`
5. Запусти программу командой `go run .` в папке `practice_01`.
6. Обрати внимание на вывод для строк разной длины. Сделай выводы и отвечай мне готовым кодом и своими мыслями.

# Global Assistant Instructions

## Strict Formatting Directive: Absolute Ban on Dollar Signs ($) and LaTeX

В чате с пользователем и во всех создаваемых markdown-файлах:
1. **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО использовать символ доллара `$`** для математики, переменных, формул или стрелочек.
2. Чат не рендерит LaTeX и превращает его в нечитаемый мусор (`$\rightarrow$`, `$$\text{...}$$`).
3. **Стрелочки:** писать ТОЛЬКО обычным текстом `->` или символом Unicode `→` (НИКОГДА не писать `$\rightarrow$`).
4. **Переменные и формулы:** писать ТОЛЬКО обычным текстом: `N = 50 000`, `N * (N + 1) / 2`, `O(N)`, `O(N^2)`.
5. Единственное исключение, где символ `$` разрешен — это синтаксис bash/терминала (`$ go run`) или денежные строки внутри кода на Go (`"$100"`).

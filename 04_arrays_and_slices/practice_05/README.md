# Практика: Спасение памяти через `copy()`

## Задача (Бизнес-требование)
Мы будем рефакторить наш гипотетический сетевой сервис из `practice_04`.
Нам нужно написать архитектурно правильную функцию, которая скачивает мегабайт логов, но безопасно возвращает только заголовок, позволяя мегабайту умереть.

## Шаги выполнения
1. Инициализируй модуль `go mod init practice_05`.
2. Создай файл `main.go`.
3. Напиши функцию `func getHeaderFromNetwork() []byte`.
4. Внутри этой функции:
   - Создай `hugeFile := make([]byte, 1000000)`.
   - **Не используй нарезку `hugeFile[:5]` для возврата!**
   - Вместо этого создай новый безопасный слайс `safeHeader` на 5 элементов, используя `make`.
   - Скопируй туда первые 5 байт из `hugeFile` с помощью встроенной функции `copy()`.
   - Верни этот `safeHeader`.
5. В функции `main()` вызови `header := getHeaderFromNetwork()`.
6. Выведи `len(header)` и `cap(header)` с помощью `fmt.Printf`.

## Ожидаемый результат
В консоли должно вывестись:
```text
Len of header: 5
Cap of header: 5
```
Если `cap` равен 5, это значит, что ты успешно отвязал слайс от гигантского массива. Сборщик мусора теперь спасет твой сервер от `Out of Memory`!

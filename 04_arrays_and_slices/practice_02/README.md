# Практика: Сбор лута и скачки памяти (append)

## Задача (Бизнес-требование)
Ты победил босса и собираешь с него лут. Мы будем по одному предмету складывать в рюкзак (слайс) и следить за тем, как Go под капотом управляет памятью, расширяя "автобус".

## Шаги выполнения (Acceptance Criteria)
1. Сделай `go mod init practice_02` в этой папке.
2. Создай файл `main.go`.
3. Создай слайс лута босса (это то, что выпало): 
   `loot := []string{"Золото", "Кинжал", "Броня", "Свиток", "Зелье"}`
4. Создай свой пустой инвентарь (пустой слайс, не инициализируй его через `make`, просто `var inventory []string`).
5. Напиши цикл `for`, который переберет массив `loot` (или просто цикл от 0 до 4).
6. На каждой итерации добавляй текущий предмет из лута в свой `inventory` с помощью `append`.
7. **Самое главное:** На каждой итерации сразу после `append` выводи в консоль сообщение с помощью `fmt.Printf`.
   Нужно вывести:
   - Какое слово мы добавили.
   - Текущую длину инвентаря (функция `len(inventory)`).
   - Текущую вместимость инвентаря (функция `cap(inventory)`).

## Ожидаемый результат
Ты должен увидеть в консоли, как `len` растет равномерно (1, 2, 3, 4, 5), а вот `cap` будет расти **скачкообразно**, каждый раз удваиваясь, когда заканчивается место.

Жду твой код! Проанализируй этот скачкообразный вывод — это именно то, как работает менеджер памяти Go.

# Экстра Практика: Обход слайсов и массивов (for range)

## Задача (Бизнес-требование)
Кузнец берет деньги за ремонт, но и оружие, и броня у игроков не меняют своих характеристик! Тебе нужно починить обе функции обновления экипировки, вспомнив разницу между итерацией по значению и по индексу.

## Шаги выполнения
1. Перейди в папку `04_arrays_and_slices/extra_practice_02`.
2. Запусти `go run main.go` и убедись, что баг присутствует (характеристики не растут).
3. **ЗАДАЧА 1 (Слайсы):** Найди и исправь логическую ошибку в цикле `for range` внутри функции `upgradeWeapons`.
4. **ЗАДАЧА 2 (Массивы):** Напиши с нуля цикл `for range` внутри функции `repairArmor`. Помни, что туда передан **указатель на массив** `*[4]int`. Вспомни синтаксический сахар Go, позволяющий обходить такие указатели так же легко, как и сами массивы.
5. (Дополнительно): Подумай, почему в функции `upgradeWeapons` нам **НЕ** нужно возвращать слайс из функции через `return` (как мы это делали с `append` в прошлой практике)?

# Практика: Инвентарь (Массив против Слайса)

## Задача (Бизнес-требование)
Твоя задача — на практике убедиться, как по-разному ведут себя массивы и слайсы при передаче в функции. Мы напишем систему экипировки и рюкзака для RPG.

## Шаги выполнения (Acceptance Criteria)
1. Сделай `go mod init practice_01` внутри этой папки.
2. Создай файл `main.go`.
3. В функции `main` создай:
   - **Массив** экипировки из 3 элементов: `equipment := [3]string{"Шлем", "Броня", "Оружие"}`
   - **Слайс** инвентаря: `inventory := []string{"Зелье", "Свиток"}`
4. Напиши функцию `BreakEquipment(eq [3]string)`. Внутри функции измени первый элемент (индекс 0) на `"Сломанный Шлем"`.
5. Напиши функцию `UseItem(inv []string)`. Внутри функции измени первый элемент (индекс 0) на `"Пустая колба"`.
6. Выведи `equipment` и `inventory` до вызова функций.
7. Вызови `BreakEquipment(equipment)` и `UseItem(inventory)`.
8. Выведи `equipment` и `inventory` после вызова функций.

Посмотри на результаты в консоли. Убедись, что одно изменилось, а другое — нет. Осознай, почему так произошло, опираясь на `THEORY.md`. Жду код!

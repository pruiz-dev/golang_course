# Теория: Синтаксический сахар для указателей на массивы

При работе с указателями на массивы (`*[5]int`) новички часто пишут математически правильный, но очень громоздкий код с явным разыменованием:

```go
func EncryptKey(arrPtr *[5]int) {
    for i := range *arrPtr {
        (*arrPtr)[i] *= 2 
    }
}
```
Здесь скобки `(*arrPtr)` обязательны, так как приоритет оператора `[i]` выше, чем у `*`.

## Идиоматичный Go
В Go встроен удобный синтаксический сахар. Если у тебя есть указатель на массив (или структуру), тебе **не нужно разыменовывать его вручную** для доступа к элементам. Компилятор сделает это за тебя.

Правильный и чистый способ написать ту же самую логику:
```go
func EncryptKey(arrPtr *[5]int) {
    // Go сам разыменует arrPtr для цикла range
    for i := range arrPtr {
        // Go сам разыменует arrPtr перед взятием индекса [i]
        arrPtr[i] *= 2 
    }
}
```

Всегда используй этот сахар — он делает код читаемым и избавляет от лишнего "визуального шума".

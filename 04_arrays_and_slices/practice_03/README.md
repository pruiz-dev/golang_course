# Практика: Мутация Массива через Указатель

## Задача (Бизнес-требование)
У нас есть массив на 5 элементов, имитирующий сырые байты криптографического ключа. Нам нужно передать этот массив в функцию-шифровальщик, которая умножит каждый байт на 2 (типа шифрует).

**Проблема:** Массивы передаются по значению. Если мы передадим сам массив, функция создаст копию, умножит копию на 2 и удалит её. Оригинальный ключ не изменится, и мы зря скопируем память.

**Решение:** Передать **указатель на массив** и изменить оригинальные данные прямо в памяти, используя правильный вид цикла `for ... range`.

## Шаги выполнения (Acceptance Criteria)
1. Сделай `go mod init practice_03`.
2. В функции `main` создай массив из 5 чисел (тип `[5]int`), например: `key := [5]int{1, 2, 3, 4, 5}`.
3. Выведи `key` в консоль до мутации.
4. Напиши функцию `EncryptKey`. Эта функция должна принимать **указатель на массив из 5 интов** (`*[5]int`).
5. Внутри `EncryptKey` напиши цикл `for`, который обойдет массив и умножит каждый его элемент на 2. 
   > **Подсказка:** Для изменения оригинала нужно использовать цикл только по индексу (`for i := range`). Обращаться к элементам можно просто по индексу `ptr[i]`, Go сам разыменует указатель.
6. В `main` вызови функцию `EncryptKey`, передав ей адрес ключа (`&key`).
7. Выведи `key` после вызова функции. Он должен превратиться в `[2, 4, 6, 8, 10]`.

Жду твой код!

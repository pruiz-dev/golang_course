# Практика: Ловушка нарезки (Slicing)

## Задача (Бизнес-требование)
Наш сервер получает из сети огромный лог-файл (симулируем его большим слайсом на 1 миллион байт). Из всего этого файла нам нужно извлечь только первую строчку — "заголовок" лога (первые 5 байт), а остальное забыть.
Твоя задача — "попасть в ловушку" и увидеть, что происходит с памятью.

## Шаги выполнения (Acceptance Criteria)
1. Сделай `go mod init practice_04`.
2. Создай файл `main.go`.
3. Внутри функции `main` создай гигантский слайс, имитирующий загруженный файл. Мы используем функцию `make`, чтобы сразу выделить место под 1 миллион элементов типа `byte`:
   ```go
   hugeFile := make([]byte, 1000000)
   ```
4. Теперь с помощью операции нарезки (slicing) создай новую переменную `header`, в которую положи только первые 5 байт из `hugeFile`.
5. Выведи в консоль через `fmt.Printf` длину (`len`) и, что самое главное, вместимость (`cap`) переменной `header`.
6. Сделай вывод: почему полученный `cap` — это проблема для сервера, который будет работать месяцами? Объясни это мне (чат-боту).

Жду твой код и твоё объяснение выведенных в консоль цифр!

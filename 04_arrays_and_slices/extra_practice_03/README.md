# Экстра Практика 03: Гранд Финал Итераций

## Задача (Бизнес-требование)
Ты разрабатываешь движок для стратегии. В коде разбросаны разные структуры данных: слайсы отрядов, жесткие массивы генералов и гигантские массивы солдат. Твоя задача — применить правильный способ обхода для каждого случая, основываясь на той глубокой теории, которую мы разобрали.

## Шаги выполнения
1. Перейди в папку `04_arrays_and_slices/extra_practice_03`.
2. `go mod init extra_practice_03`
3. В файле `main.go` тебя ждут 3 задачи:
   - **Задача 1:** Использовать фичу Go 1.22 (`for range 5`) для генерации данных в слайсе.
   - **Задача 2:** Починить баг с невидимым копированием массива при мутации.
   - **Задача 3:** Написать функцию, которая принимает огромный массив по указателю `*[100000]int` (чтобы избежать копирования 800 КБ памяти при вызове функции), обходит его через `range` и возвращает результат.
4. Запусти `go run main.go`. Если все ожидаемые значения совпали с реальными — ты победил!

Жду финальный код. Это последняя проверка на прочность перед тем, как мы окончательно уйдем в Мапы!

# Практика: Модули, Пакеты и Экспорт

## Задание
Отличное решение — вернуться и освежить память! В Go правильная структура проекта — это фундамент, без которого дальше не уехать. Эта практика нацелена на закрепление работы с модулями, пакетами и видимостью переменных (Public/Private).
Мы будем писать код с нуля (Blank Slate).

Тебе предстоит написать простейший магазин, который будет состоять из двух разных пакетов (папок): главного (`main`) и вспомогательного (`discount`). Мы свяжем их вместе.

### Шаги:
1. Создай папку `practice_01` внутри `00_modules_and_packages`.
2. Перейди в неё и инициализируй модуль: `go mod init shop_app`.
3. Внутри этой папки создай новую папку (поддиректорию) с именем `discount`.
4. Внутри папки `discount` создай файл `calculator.go`. 
   - Объяви пакет: `package discount`.
   - Создай неэкспортируемую (с маленькой буквы) константу `baseDiscount` равную `10` (базовая скидка).
   - Создай экспортируемую (с большой буквы) функцию `Calculate(price int) int`, которая будет возвращать итоговую цену за вычетом `baseDiscount`.
5. Вернись в папку `practice_01` (корень твоего модуля) и создай файл `main.go`.
   - Объяви `package main`.
   - Импортируй свой пакет. *Подсказка: путь импорта всегда состоит из имени модуля (`shop_app`) и названия папки, то есть `import "shop_app/discount"`*.
   - Внутри `func main()` вызови функцию `discount.Calculate(100)` и выведи результат в консоль (ожидается 90).
6. Запусти приложение через `go run main.go`.

**Бонусная проверка (Экспорт):** Попробуй из `main.go` вывести на экран значение константы `discount.baseDiscount`. Убедись, что компилятор выдаст ошибку доступа (так как переменная приватная). Затем верни рабочий код.

Присылай готовые файлы на ревью!

# Практика: Две программы и коварные импорты

## Задание
Эта хардкорная практика закроет все твои пробелы. Мы создадим один репозиторий (модуль), внутри которого будут жить **две совершенно разные программы**, которые переиспользуют один и тот же код из хитрой библиотеки.

Мы нарушим конвенцию именования, чтобы ты руками прочувствовал разницу между "Путем к папке" и "Именем пакета".

### Шаги:
1. Создай папку `extra_practice_01` внутри `00_modules_and_packages`.
2. Перейди в неё и инициализируй модуль: `go mod init tricky_app`.

**Часть 1: Общая библиотека с подвохом**
3. Создай папку `internal/db_connector` (создай папку `internal`, а в ней `db_connector`).
4. Внутри `db_connector` создай файл `postgres.go`.
   - Внимание! Объяви пакет как `package database` (не `db_connector`!).
   - Создай экспортируемую функцию `Connect()`, которая просто выводит в консоль `"Подключение к БД успешно!"`.

**Часть 2: Программа №1 (Сервер с двумя файлами)**
5. Вернись в корень `extra_practice_01` и создай папку `cmd/server` (папку `cmd`, в ней `server`).
6. Внутри `server` создай файл `main.go`:
   - `package main`
   - Напиши пустую `func main()`
7. Внутри `server` создай **второй файл** `helpers.go`:
   - `package main` (тот же пакет, потому что та же папка!)
   - Создай функцию `LaunchServer()`, которая внутри себя вызывает функцию `Connect()` из твоей библиотеки (не забудь импортировать путь `"tricky_app/internal/db_connector"` и вызвать как `database.Connect()`).
8. Вернись в `main.go` и внутри `func main()` просто вызови `LaunchServer()`.
   *(Подсказка: `helpers.go` и `main.go` лежат в одной папке, поэтому импортировать `helpers.go` не нужно, `main` его увидит сам!)*

**Часть 3: Программа №2 (Клиент)**
9. Вернись в папку `cmd` и создай рядом с `server` папку `client`.
10. Внутри `client` создай файл `main.go`:
    - `package main`
    - Внутри `func main()` сразу импортируй библиотеку и вызови `database.Connect()`, а затем выведи `"Клиент запущен"`.

### Запуск и проверка:
У тебя получилось две независимые программы. Запускать их нужно отдельно!
1. Запусти сервер: `go run ./cmd/server` (помнишь, почему нужна точка, а не имя файла? Потому что у нас там два файла: `main.go` и `helpers.go`, и компилятору нужно склеить оба!).
2. Запусти клиент: `go run ./cmd/client` (здесь файл один, но `go run .` работает безотказно).

Жду весь этот шедевр на ревью!

# Практика 02: Ловушки `for range`

## Задание
Тебе достался кусок кода, в котором разработчик попытался выдать всем сотрудникам премию, но скрипт не сработал — зарплаты остались прежними. Твоя задача: найти концептуальную ошибку и исправить её.

### Шаги:
1. Создай папку `practice_02` внутри `02_control_flow`.
2. Инициализируй модуль: `go mod init practice_02`.
3. Создай `main.go` и скопируй туда этот код:

```go
package main

import "fmt"

func main() {
	salaries := []int{100, 200, 300}
	fmt.Println("Зарплаты до:", salaries)

	// ПЛОХОЙ КОД: Попытка повысить зарплату всем на 50
	for _, s := range salaries {
		s = s + 50
	}

	fmt.Println("Зарплаты после:", salaries)
	
	// Твоя задача сделать так, чтобы массив salaries реально изменился!
}
```

### Что нужно сделать:
1. Запусти текущий код через `go run .` и убедись, что зарплаты действительно не изменились (магия копирования по значению в действии).
2. Перепиши цикл `for range` так, чтобы мы обращались к элементам по индексу и реально модифицировали исходный массив `salaries`. (Подглядывай в Пункт 4 в `THEORY.md`, если забыл синтаксис).
3. Убедись, что вывод скрипта покажет `[150 250 350]`.

Присылай исправленный код на ревью!

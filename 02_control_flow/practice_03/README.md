# Практика 03: Охота за сокровищами (Метки)

## Задание
Эта практика нацелена на тренировку "мышечной памяти". Ты будешь писать код с абсолютного нуля, без шаблонов для копипасты.
Представь, что у нас есть двумерная карта (матрица), на которой спрятано сокровище (символ `X`). Твоя задача — найти координаты сокровища и немедленно прекратить поиски, используя метки для выхода из вложенных циклов.

### Шаги:
1. Создай папку `practice_03` внутри `02_control_flow`.
2. Инициализируй модуль: `go mod init practice_03`.
3. Создай `main.go`. Напиши весь код самостоятельно.

### Логика программы:
1. Задай двумерный массив (карту) типа `[][]string`. Пусть это будет матрица 3x3.
   Например, можешь инициализировать её так:
   ```go
   var mapGrid = [][]string{
       {"O", "O", "O"},
       {"O", "X", "O"},
       {"O", "O", "O"},
   }
   ```
2. Напиши два вложенных цикла `for range`: внешний для перебора строк матрицы (`row`), внутренний для перебора ячеек внутри строки (`cell`). Тебе понадобятся индексы!
3. Добавь **Метку** (например, `SearchLoop:`) прямо перед внешним циклом.
4. Внутри внутреннего цикла проверяй: если значение ячейки равно `"X"`, выведи в консоль сообщение: `Сокровище найдено на координатах [индекс_строки, индекс_ячейки]`.
5. Сразу после вывода сообщения используй `break` с именем твоей метки, чтобы мгновенно выйти из обоих вложенных циклов (иначе он продолжит перебирать пустые клетки).
6. В самом конце функции `main` (после всех циклов) выведи `Поиск завершен`.

### Проверка:
Запусти программу. Сообщение `Поиск завершен` должно вывестись в самом конце. Убедись, что после находки крестика цикл не делает лишних итераций. Присылай готовый код!

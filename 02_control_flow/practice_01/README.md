# Практика 01: Мастер `switch` и `if`

## Задание
Твоя задача — отрефакторить нечитаемый код, написанный стажером на каскадах `if-else`, превратив его в идиоматичный Go-код, используя всю мощь `switch` и инициализацию в блоке условия.

### Шаги:
1. Создай папку `practice_01` внутри `02_control_flow`.
2. Инициализируй модуль: `go mod init practice_01`.
3. Создай `main.go` и скопируй туда этот "плохой" код:

```go
package main

import (
	"fmt"
	"math/rand"
)

// Имитируем запрос к серверу
func fetchStatusCode() int {
	codes := []int{200, 201, 400, 404, 500, 503, 999}
	return codes[rand.Intn(len(codes))]
}

func main() {
	// ПЛОХОЙ КОД: Переменная code торчит снаружи, хотя нужна только для проверок
	code := fetchStatusCode()

	if code == 200 || code == 201 {
		fmt.Printf("Код %d: Успех\n", code)
	} else if code == 400 || code == 404 {
		fmt.Printf("Код %d: Ошибка клиента\n", code)
	} else if code == 500 || code == 503 {
		fmt.Printf("Код %d: Ошибка сервера. Требуется перезапуск.\n", code)
	} else {
		fmt.Printf("Код %d: Неизвестный статус\n", code)
	}
    
    // ПЛОХОЙ КОД: Мы всё еще имеем доступ к code здесь, хотя она нам больше не нужна.
    fmt.Println("Последний обработанный код был:", code)
}
```

### Что нужно сделать (Рефакторинг):
1. **Избавься от `code` во внешнем scope.** Используй блок инициализации (Init statement) прямо внутри конструкции `switch`, чтобы переменная `code` создавалась и жила **только** внутри `switch`. (Ты больше не должен иметь возможность вывести её в самом конце `main`, эту строку `fmt.Println` придется удалить или закомментировать).
2. **Замени `if-else` на `switch`.** Избавься от всех `if-else`.
3. **Используй списки значений.** В `case` перечисли статусы через запятую, чтобы избавиться от логических операторов `||` (OR).
4. Проверь работу программы через `go run .` (запусти несколько раз, чтобы убедиться, что разные случайные статусы обрабатываются правильно).

Скидывай отрефакторенный код!

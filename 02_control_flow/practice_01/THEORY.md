# Теория: Особенности `if` и мощь `switch` в Go

В Go убрали всё лишнее из управляющих конструкций (нет круглых скобок вокруг условий), но добавили несколько киллер-фич.

## 1. Инициализация (Init statement) в `if` и `switch`
Ты уже сталкивался с этим, когда обрабатывал ошибки. В Go можно объявить переменную прямо перед условием, в одной строке.
```go
if val := getValue(); val > 10 {
    // val доступна только внутри этого блока if (и связанных else)
    fmt.Println("Больше 10:", val)
}
// Здесь val уже не существует (out of scope)
```
Аналогичный блок инициализации есть и у `switch`. Давай разберем эту конструкцию детально, так как она состоит из двух частей, разделенных точкой с запятой `;`:

```go
switch status := getStatus(); status {
// ...
}
```
Здесь:
1. `status := getStatus()` — это **блок инициализации**. Выполняется один раз. Мы создаем локальную переменную `status`.
2. `;` — разделитель.
3. `status` (второе слово) — это **значение, которое мы будем сравнивать**. Мы говорим `switch`: "Сравнивай значение этой переменной со значениями в каждом `case`".

Если бы мы написали `switch code := fetchStatusCode(); {` (без второго слова, оставив пустоту после точки с запятой), это сработало бы как "пустой switch" (switch true), и тогда в каждом `case` пришлось бы писать полное условие: `case code == 200:`.

## 2. Switch: Безопасный по умолчанию
В языках C/C++ или Java, если ты забыл написать `break` в конце блока `case`, выполнение провалится в следующий `case`. В Go это сделано наоборот для безопасности:
* **`break` встроен по умолчанию**. Как только `case` отработал, `switch` завершается.
* Если тебе *нужно* провалиться в следующий `case` (как в C), ты должен явно написать ключевое слово `fallthrough`.

```go
switch status := getStatus(); status {
case "error":
    fmt.Println("Произошла ошибка")
    fallthrough // Выполнит код следующего case (unknown)!
case "unknown":
    fmt.Println("Статус неизвестен")
}
```

## 3. Множественные условия в одном case
Вместо того чтобы писать много `case` с одинаковой логикой (или использовать `fallthrough`), в Go можно перечислять значения через запятую:
```go
case 1, 3, 5, 7, 9:
    fmt.Println("Нечетное число")
```

## 4. Пустой switch (Switch true) и Интервалы
Часто возникает вопрос: можно ли в Go проверить интервал значений, написав что-то вроде `case 1..5:`? 
**Ответ: нет.** Go не поддерживает специальный синтаксис интервалов в `switch`.

Если тебе нужно проверить диапазоны (больше, меньше, между), вместо длинных цепочек `if-else if-else` в Go принято использовать **пустой `switch`** без условия. В этом случае он работает как `switch true`, и в каждом `case` ты пишешь полноценное логическое выражение:

```go
score := 85
switch { // Условие не передано (считай, что тут скрыто true)
case score >= 90 && score <= 100:
    fmt.Println("Отлично")
case score >= 80 && score < 90:
    fmt.Println("Хорошо")
default:
    fmt.Println("Надо подтянуть")
}
```
Это читается гораздо чище, чем каскад вложенных `if`, и полностью решает проблему отсутствия встроенных интервалов.

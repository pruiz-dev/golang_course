# Практика: Убийство программы (Fatal Error)

## Задача
Иногда лучший способ запомнить ошибку — это создать её своими руками. Твоя задача — намеренно уронить программу с фатальной ошибкой `concurrent map writes`.

## Шаги выполнения
1. Перейди в папку `05_hash_maps/practice_05` и сделай `go mod init practice_05`.
2. Я оставил тебе скелет в `main.go`. Там создается пустая мапа и запускается бесконечный цикл, который пишет в мапу.
3. Но одного цикла мало — программа работает в один поток.
4. Добавь **горутину**, которая параллельно будет тоже бесконечно писать в эту же мапу.
   *(Подсказка: запустить код параллельно можно, просто написав слово `go` перед анонимной функцией).*
5. Запусти код `go run main.go`.

**Ожидаемый результат:** Твой терминал взорвется красным текстом с надписью `fatal error: concurrent map writes`. 

Присылай код, который смог убить программу!

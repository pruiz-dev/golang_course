# Практика: CRUD и Comma Ok

## Задача
Мы разрабатываем игру, и нам нужна база данных профилей игроков онлайн (словарь, где ключ — никнейм `string`, а значение — уровень игрока `int`).

## Шаги
1. Сделай `go mod init practice_01`.
2. В функции `main` создай пустую мапу `players` через `make`.
3. Добавь двух игроков: `"Fighter"` (10 уровень) и `"Mage"` (5 уровень).
4. Удали `"Mage"` с помощью функции `delete()`.
5. Попробуй извлечь уровень игрока `"Rogue"` в переменную `rogueLvl` (мы его не добавляли!). Выведи её в консоль, чтобы убедиться, что Go отдал тебе Zero Value (`0`).
6. Используй идиому `comma ok`, чтобы попытаться достать игрока `"Fighter"` и игрока `"Mage"`. Выведи в консоль соответствующие сообщения в зависимости от того, вернул ли `ok` значение `true` или `false`.

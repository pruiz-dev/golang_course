# Теория: Основы Хэш-таблиц (Maps) в Go

Слайсы и массивы — это поиск по целочисленному индексу `0, 1, 2...` со сложностью $O(1)$. 
Но в бизнесе часто нужно искать данные по текстовому ключу или уникальному ID пользователя. Для этого существуют Хэш-таблицы, которые в Go называются просто **Maps (Мапы)**.

## 1. Объявление и Инициализация

Мапа в Go — это ссылочный тип данных (как и слайс). По умолчанию неинициализированная мапа равна `nil`.
Ключом может быть любой тип, который можно сравнить с помощью `==` (строки, числа, булевы значения). Слайсы, мапы и функции **НЕ МОГУТ** быть ключами!

```go
// 1. Создание через make (Идиоматично для пустой мапы)
// map[Тип_Ключа]Тип_Значения
dictionary := make(map[string]int)

// 2. Литерал (Идиоматично, если сразу есть данные)
ages := map[string]int{
    "Alice": 25,
    "Bob":   30, // Обрати внимание на запятую в конце!
}
```

## 2. CRUD Операции

### Создание и Обновление (Create / Update)
```go
dictionary["Golang"] = 100 // Если ключа нет - создаст
dictionary["Golang"] = 200 // Если ключ есть - обновит
```

### Удаление (Delete)
Для удаления используется встроенная функция `delete`.
```go
delete(dictionary, "Golang")
// Если ключа "Golang" не было, паники не произойдет. Функция просто ничего не сделает.
```

### Чтение и Zero Values (Read)
```go
val := dictionary["Java"]
```
**Супер-особенность Go:** Если ты попробуешь получить значение по ключу, которого **НЕТ** в мапе, Go не выбросит ошибку и не вернет `nil`! Он вернет **Zero Value** для типа значения.
В примере выше `dictionary` хранит `int`. Значит, если ключа "Java" нет, `val` будет равен `0`.

## 3. Проверка наличия (Comma Ok Идиома)
Из-за особенности выше возникает проблема: как отличить ситуацию, когда ключ реально существует и его значение `0`, от ситуации, когда ключа вообще нет в мапе?

Для этого используется второй (опциональный) возвращаемый параметр типа `bool`, который принято называть `ok`.

```go
val, ok := dictionary["Java"]

if ok {
    fmt.Printf("Ключ есть, значение: %d\n", val)
} else {
    fmt.Println("Такого ключа нет в мапе!")
}
```
Это называется **Идиома "comma ok" (запятая ок)**, и ты будешь использовать её в Go сотни раз каждый день.

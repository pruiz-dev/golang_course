# Практика: Замер скорости Эвакуации

## Задача
Написать код, который наглядно покажет разницу в скорости заполнения "медленной" мапы (с эвакуациями) и "быстрой" мапы (с пред-аллокацией бакетов).

## Шаги выполнения
1. Перейди в `05_hash_maps/practice_04` и выполни `go mod init practice_04`.
2. Я уже подготовил для тебя скелет кода в `main.go` с использованием пакета `time`.
3. Напиши цикл `for` (на 5 000 000 итераций), который добавляет элементы в `slowMap`. Ключом пусть будет сам счетчик цикла `i`, а значением — что угодно (например, `i * 2`).
4. Напиши точно такой же цикл для `fastMap`.
5. Запусти `go run main.go` и сравни результаты вывода.

Посмотри на консоль. Напиши мне, во сколько раз `fastMap` отработала быстрее, чем `slowMap`!

# Практика: Ощути хаос мапы

## Задача
Убедиться на практике, что порядок итерации в мапе намеренно хаотичен, и написать стандартный цикл вывода.

## Шаги выполнения
1. Сделай `go mod init practice_02`.
2. Создай `main.go`.
3. Создай мапу, используя синтаксис литерала, и заполни её минимум 5-ю элементами. Например, это может быть словарь-переводчик цветов:
   ```go
   colors := map[string]string{
       "Red":   "Красный",
       "Green": "Зеленый",
       "Blue":  "Синий",
       "Black": "Черный",
       "White": "Белый",
   }
   ```
4. Напиши цикл `for key, value := range`, который выведет все ключи и значения в формате: `Цвет Red переводится как Красный`.
5. Запусти `go run main.go` **минимум 3-4 раза подряд**.
6. Посмотри в консоль и убедись, что создатели Go действительно рандомизировали обход.

# Практика: Ошибка неадресуемости

## Задача
Убедиться на практике, что компилятор Go защищает нас от утечек памяти, запрещая брать адреса элементов внутри бакетов мапы. А затем найти обходной путь для изменения сложных структур внутри мапы.

## Шаги выполнения
1. Перейди в папку `05_hash_maps/practice_03` и сделай `go mod init practice_03`.
2. Создай `main.go`.
3. Создай структуру `User` с одним полем `Age int`.
4. Создай мапу `users := make(map[string]User)`.
5. Добавь туда пользователя: `users["Alice"] = User{Age: 25}`.
6. Попытайся увеличить возраст Алисы напрямую: `users["Alice"].Age = 26`. 
   Попробуй скомпилировать (через `go run main.go`). Убедись, что компилятор выдает ошибку: `cannot assign to struct field users["Alice"].Age in map`.
7. Закомментируй предыдущий шаг и попытайся взять указатель на структуру Алисы: `ptr := &users["Alice"]`. 
   Попробуй скомпилировать. Убедись, что компилятор выдает ошибку: `cannot take the address of users["Alice"]`.
8. **Главная задача:** Найди правильный способ изменить возраст Алисы на 26. Тебе придется достать всю структуру из мапы целиком в локальную переменную, изменить копию и положить ее обратно в мапу по ключу `"Alice"`! 

Жду твой итоговый рабочий код (строки с ошибками компиляции закомментируй, чтобы код запускался) и обновленный возраст Алисы в консоли!
